# Дневник здоровья

Дневник артериального давления с выгрузкой из Omron RS7 Intelli IT по
Web Bluetooth. React 19 + Vite, dev-сервер на порту 5199 (https — Web Bluetooth
без него не работает).

## Правки интерфейса

Изменения UI идут через навык `impeccable` — но по порогу, а не на каждую
строчку. Порог такой:

- **Мелочь правим напрямую, навык не зовём.** Текст, отступ, цвет одного
  элемента, починка одного компонента, опечатка в подписи.
- **`impeccable` зовём**, когда меняется экран целиком, добавляется новый раздел
  или компонент, идёт редизайн, или просьба сформулирована как «сделай
  нормально / проверь интерфейс / почему это выглядит дёшево».
- Внутри навыка читаем **один нужный reference-файл** под задачу (`layout.md`,
  `polish.md`, `audit.md`, `typeset.md`), а не весь каталог из 28 штук.
- **Live-режим** (браузерная сессия с правками на лету) — только по прямой
  просьбе: он дорогой.

## Проверка вёрстки

Три уровня, от дешёвого к дорогому. Ключи и токены лежат в
`~/.browserstack.env`, **в чат и в код их не выводить**.

### 1. Локально — на каждую правку

`npm run typecheck`, затем запуск и осмотр через встроенный браузер, включая
мобильную ширину. Большинство дефектов вёрстки видно здесь.

### 2. Percy — перед показом и после заметных правок

```
npm run visual
```

Собирает, поднимает просмотр, обходит 11 экранов в двух темах и отправляет
снимки в Percy; тот перерисовывает их в своём облаке на 360, 768 и 1280 и
сравнивает с прошлым прогоном. Расхождения смотреть в кабинете Percy.

- **Минуты BrowserStack Automate он не тратит** — Percy отдельный продукт с
  отдельным счётчиком (5000 снимков в месяц на бесплатном плане, прогон стоит
  66).
- **Часы в прогоне заморожены** на `2026-08-15T10:30`, данные засеиваются
  относительно этой даты. Без этого «составлен 15 августа» и «хватит на 6 дней»
  давали бы расхождение на каждом запуске. Детерминизм проверен: два
  независимых прогона дают побайтово одинаковую разметку.
- Меняя посев или список экранов в `tools/visual.mjs`, помните, что первый
  прогон после этого станет новым эталоном.

### 3. BrowserStack Live — руками, когда нужны настоящие устройства

**Automate у аккаунта недоступен:** оплачен только `Live — Desktop & Mobile`,
а Automate остался на бесплатном триале, и его 100 минут выбраны (102 минуты за
133 сессии). Минуты триала не возобновляются. Поэтому скриптовых прогонов через
`hub-cloud.browserstack.com` больше нет — навык `browserstack` для этого проекта
не применим, пока не куплен Automate (от $59/мес) или не одобрена заявка в их
программу для открытого кода.

Live оплачен и безлимитен, но управляется только руками. Зовём его ради того,
чего не даёт ни локальная эмуляция, ни Percy: настоящий iOS Safari, реальная
плотность экрана и системные шрифты, нижняя панель жестов.

**Чего не проверить нигде в облаке:** Web Bluetooth. Рядом с фермой нет
тонометра, а iOS Safari этот API не поддерживает в принципе. Сценарий
сопряжения проверяется живым устройством на своей машине.

## Справочник лекарств

Два файла, два государственных реестра, два генератора — поиск в приложении
один, склейка в `mergeBooks`.

| Файл | Что внутри | Источник | Команда |
|---|---|---|---|
| `public/drugs.json` | лекарства, в том числе гомеопатия | ГРЛС Минздрава, ежедневный ZIP | `npm run drugs` |
| `public/supplements.json` | БАДы | реестр свидетельств о госрегистрации, форма ЕАЭС | `npm run supplements` |

- **Руками не править ни тот, ни другой.** Все изменения — в
  `tools/build_drugs.py` и `tools/build_supplements.py` (нужен python3, для
  первого ещё openpyxl).
- Из браузера реестры не забрать: у выгрузки ГРЛС нет заголовков CORS, реестр
  БАДов отдаётся постранично и только по http. Поэтому файлы лежат в бандле и
  подгружаются лениво при открытии формы препарата.
- Дата выгрузки хранится внутри файла и показывается в интерфейсе: справочник
  устаревает, и молчать об этом нельзя.
- Реестр БАДов выкачивается ~300 страницами по сотне записей, страницы
  кэшируются в `tools/out/sgr`. Полный прогон занимает минут пятнадцать; чтобы
  забрать свежее, каталог кэша нужно очистить.
- **Российский реестр свидетельств старой формы (`fp.crc.ru/gosregfr`)
  бесполезен**: база заморожена на 24 марта 2019 года и на любой запрос
  отвечает «Сбой при работе с базой данных». Рабочий — только евразийский
  (`fp.crc.ru/evrazes`).
- Имена файлов не версионируются хэшем, поэтому в `public/sw.js` у них
  отдельная стратегия («отдать из кэша, обновить в фоне»). Меняя структуру
  файлов, поднимайте версию кэша.

## Общее

Не запускать оба навыка на одну мелкую задачу. Если сомневаешься, нужен ли
тяжёлый прогон, — спроси одной строкой, а не запускай на всякий случай.
