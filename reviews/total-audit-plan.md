4. Визуальные состояния: три концепта, два прежних режима, светлая/тёмная тема, normal/xlarge, клавиатура, длинный текст, прокрутка, Back и поворот.
5. Независимые узкие критики: расчёты; сохранение/обмен; навигация/уведомления. Root — физический Huawei и визуальный осмотр.

## Среда и ограничения
На физическом Huawei MNA-LX9 установлен отдельный пакет io.github.leonidan1988.omronbp.audit из того же кода, отдельная база и синтетические данные. Рабочий дневник не засевается и не удаляется. Тесты через WebView DevTools доказывают выполнение кода на телефоне; физические ADB-касания/клавиатура/Back учитываются отдельно. Облачный обмен с настоящими ключами не выполняется. Настоящие iOS, доставка Bluetooth с физического тонометра, весь срок фоновой работы и все комбинации ОС не считаются проверенными без свидетельств.

## Правило результата
Для каждого P1/P2: входные данные → действия → ожидание → фактический результат → файл/строка → способ исправления. Список проверенных сценариев и незакрытых областей публикуется отдельно. Зелёный обход экранов не заменяет проверку записи и конкурентных действий. Production-код в ходе ревью не меняется.
